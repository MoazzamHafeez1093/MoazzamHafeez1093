## 🔬 Featured Research

### ⚡ AWS Lambda INIT Phase Billing — First Empirical Study (2026)

</div>

> AWS changed how they bill Lambda cold starts in August 2025. Every existing cost model missed it. I ran 600 experiments across 3 workload intensities on real AWS infrastructure to find out exactly what this means for deployment decisions.

| Finding | Value |
|---|---|
| 🎯 Cost crossover — light workload | ~82,000 requests/day |
| 🎯 Cost crossover — heavy workload | ~50,000 requests/day |
| 📉 Workload-driven threshold shift | **39% lower** |
| 🧪 Total experimental runs | **600 on AWS us-east-1** |
| 📚 Prior papers that missed this | **13 out of 13** |

```
Lambda is cheaper below the crossover → Docker EC2 is cheaper above it
The threshold is NOT fixed — it shifts with workload complexity
This cost component was $0.00 in ALL prior research
```
